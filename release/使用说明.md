# 纸间 · Interleaf · 开始使用

双击“纸间.exe”即可打开，无需安装。也可以运行安装包。

1. 点击左上角“导入论文”，选取 PDF。
2. 左侧填写研究问题、主要贡献、核心方法、实验结果、局限与启发；右侧阅读原文。
3. 选中文字后点击“翻译”，或保存摘录与高亮。
4. 回到论文库，可以创建分类、标记已读、按表格回顾和导出。

笔记自动保存。资料存放在系统应用数据目录，可在“设置与备份”查看；移动程序不会带走资料。迁移电脑请导出完整备份。

Google 翻译不需要 API 密钥，需要可访问 Google 的网络。默认使用系统代理；必要时可在设置填写代理地址或切换 Google 翻译源。免密钥接口可能限流。

扫描 PDF 暂不支持直接划词，需先做 OCR。高亮保存在论文库，不改写原始 PDF。
