# 纸间 · Interleaf · 开始使用

免安装版双击“Interleaf.exe”即可打开；本机桌面快捷方式叫“纸间”。也可以运行安装包。

v0.1.3：更新为暖珊瑚色与米白纸页图标；论文列表直接显示标题与作者，移除标题前的 PDF 标识。

v0.1.4：鼠标放在右侧 PDF 阅读区，按住 Ctrl 向上滚动可放大、向下滚动可缩小，范围为 50%～250%。顶部百分比同步更新，点击百分比恢复适合宽度；普通滚轮仍用于翻页滚动。

1. 点击左上角“导入论文”，选取 PDF。
2. 左侧填写研究问题、主要贡献、核心方法、实验结果、局限与启发；右侧阅读原文。
3. 选中文字后会自动翻译，也可保存摘录与高亮。
4. 回到论文库，可以创建分类、标记已读、按表格回顾和导出。

工作台上方“笔记”“原文”按钮可以独立开关两侧面板，隐藏后保留原有位置。

v0.1.5：编辑／预览切换按钮移到笔记栏顶部，位于“自定义笔记栏目”齿轮的左侧；滚动笔记时仍可直接切换。

翻译浮窗可以拖动标题栏；拖动后后续选词继续在该位置更新。关闭浮窗后下次选词重新靠近选区出现；隐藏原文或离开论文也会重置位置。

笔记自动保存。资料存放在系统应用数据目录，可在“设置与备份”查看；移动程序不会带走资料。迁移电脑请导出完整备份。

Google 翻译不需要 API 密钥，需要可访问 Google 的网络。默认使用系统代理；必要时可在设置填写代理地址或切换 Google 翻译源。免密钥接口可能限流。

扫描 PDF 暂不支持直接划词，需先做 OCR。高亮保存在论文库，不改写原始 PDF。
